# SQL 1주차 정리

## 1. 데이터와 정보

데이터는 관찰하거나 측정해서 얻은 사실이나 값이다.

정보는 데이터를 의사결정에 쓸 수 있게 정리한 결과다.

## 2. 데이터베이스

데이터베이스는 여러 사람이 함께 사용할 목적으로 저장하고 관리하는 데이터의 모음이다.

## 3. DBMS

DBMS는 데이터베이스를 관리해주는 프로그램이다.

예:
- MariaDB
- MySQL
- PostgreSQL
- SQLite

## 4. SQL

SQL은 DBMS 또는 데이터베이스에 명령을 내리는 언어다.

## 5. SQL 명령어

SELECT = 조회

INSERT = 추가

UPDATE = 수정

DELETE = 삭제

CREATE TABLE = 테이블 만들기

## 6. SQL 분류

DML = 데이터를 다루는 명령어

예:
- SELECT
- INSERT
- UPDATE
- DELETE

DDL = 데이터베이스의 구조를 만드는 명령어

예:
- CREATE TABLE
- ALTER TABLE
- DROP TABLE

## 7. 오늘 이해한 것

SQL은 데이터베이스에 명령하는 언어다.

SELECT는 조회다.

DML은 데이터를 다루고, DDL은 구조를 다룬다.
